- Small: 14px, Medium

## Contraste

Todos los textos cumplen WCAG AA (4.5:1 mínimo):
- Texto #0F172A sobre #FFFFFF → 17.8:1 
- Texto #E11D48 sobre #FFF1F2 → 7.2:1 
- Texto blanco sobre #E11D48 → 5.5:1
